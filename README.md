# Ontheway

- 算法层：**PID** 滤波（IIR FIR 低通 互补融合 卡尔曼 etc.） ROS SLAM 计算机视觉 OpenCV 机器视觉（轻量化端部署）OpenMV & K230 & MaixCam 路径规划搜索 BFS / A星
- 代码层：**C C++ MicroPython 命令行（Linux）** 的运用 模块化编程 **高内聚低耦合** 有限状态机（FSM） 基于 Git 的个人代码版本管理与团队协作
- 应用层 / 嵌入式层：十类主流 MCU 实战项目经验 STM NXP Infineon TI STC8051 ESP32 WCH 百度Edgeboard 龙芯Loongson 兆易GD32 熟悉ARM-Cortex和51硬件架构及基础汇编指令 各类外设的熟练运用 **GPIO NVIC中断 ADC 定时器 UART SPI IIC CAN RTC 看门狗 操作系统:freertos&linux（任务创建调度和管理，同步与通信，内存管理）**  编译烧录调试工具链完善（Keil / VSCode CMake / Ozone etc.）debug经验丰富 了解树莓派，香橙派基于Linux的单板小电脑
